# S8. Denial of Service (DoS)[¶](https://scs.owasp.org/SCSVS/12-SCSVS-BLOCK/#s8-denial-of-service-dos "Permanent link")

## Control Objective[¶](https://scs.owasp.org/SCSVS/12-SCSVS-BLOCK/#control-objective "Permanent link")

Establish practices and mechanisms to prevent Denial of Service (DoS) attacks that can disrupt contract functionality and availability.
