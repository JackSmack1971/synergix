# S7. Arithmetic and Logic Security[¶](https://scs.owasp.org/SCSVS/11-SCSVS-ORACLE/#s7-arithmetic-and-logic-security "Permanent link")

## Control Objective[¶](https://scs.owasp.org/SCSVS/11-SCSVS-ORACLE/#control-objective "Permanent link")

Establish secure arithmetic and logic practices to prevent vulnerabilities such as overflow/underflow and ensure the integrity of calculations within smart contracts.
