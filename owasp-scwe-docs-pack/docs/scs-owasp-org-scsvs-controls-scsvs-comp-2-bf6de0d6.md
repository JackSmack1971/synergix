# SCSVS-COMP-2[¶](https://scs.owasp.org/SCSVS/controls/SCSVS-COMP-2/#scsvs-comp-2 "Permanent link")

## S11.2 NFT Security[¶](https://scs.owasp.org/SCSVS/controls/SCSVS-COMP-2/#s112-nft-security "Permanent link")

### Control Objective[¶](https://scs.owasp.org/SCSVS/controls/SCSVS-COMP-2/#control-objective "Permanent link")

Implement best practices for non-fungible tokens to safeguard against vulnerabilities.

### S11.2.A Best Practices for Non-Fungible Tokens[¶](https://scs.owasp.org/SCSVS/controls/SCSVS-COMP-2/#s112a-best-practices-for-non-fungible-tokens "Permanent link")

| **SCSVS VR ID** | Requirement | L1 | L2 | L3 | SWE |
| --- | --- | --- | --- | --- | --- |
| S11.2.A1 | Implement standards and best practices for NFT creation, management, and transfer to prevent common vulnerabilities. |  | ✓ | ✓ |  |
| S11.2.A2 | Ensure proper metadata integrity and prevent unauthorized minting or transfers. |  | ✓ | ✓ |  |
| S11.2.A3 | Safeguard against potential exploits related to royalty payments or token burns. |  | ✓ | ✓ |  |
