# SCSVS-CRYPTO-3[¶](https://scs.owasp.org/SCSVS/controls/SCSVS-CRYPTO-3/#scsvs-crypto-3 "Permanent link")

## S6.3 Secure Random Number Generation[¶](https://scs.owasp.org/SCSVS/controls/SCSVS-CRYPTO-3/#s63-secure-random-number-generation "Permanent link")

### Control Objective[¶](https://scs.owasp.org/SCSVS/controls/SCSVS-CRYPTO-3/#control-objective "Permanent link")

Implement best practices for secure random number generation to ensure unpredictability and resistance against manipulation.

### S6.3.A Best Practices for Randomness[¶](https://scs.owasp.org/SCSVS/controls/SCSVS-CRYPTO-3/#s63a-best-practices-for-randomness "Permanent link")

| **SCSVS VR ID** | Requirement | L1 | L2 | L3 | SWE |
| --- | --- | --- | --- | --- | --- |
| S6.3.A1 | Ensure that random number generation follows best practices and uses secure sources of entropy. |  | ✓ | ✓ |  |
| S6.3.A2 | Verify that any random number generation is resistant to manipulation and prediction. |  | ✓ | ✓ |  |
