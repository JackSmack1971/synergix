# SCSVS-BRIDGE-4[¶](https://scs.owasp.org/SCSVS/controls/SCSVS-BRIDGE-4/#scsvs-bridge-4 "Permanent link")

## S9.4 Decentralized Storage[¶](https://scs.owasp.org/SCSVS/controls/SCSVS-BRIDGE-4/#s94-decentralized-storage "Permanent link")

### Control Objective[¶](https://scs.owasp.org/SCSVS/controls/SCSVS-BRIDGE-4/#control-objective "Permanent link")

Ensure data integrity, security, and availability for data stored in decentralized storage solutions.

### S9.4.A IPFS, Arweave[¶](https://scs.owasp.org/SCSVS/controls/SCSVS-BRIDGE-4/#s94a-ipfs-arweave "Permanent link")

| **SCSVS VR ID** | Requirement | L1 | L2 | L3 | SWE |
| --- | --- | --- | --- | --- | --- |
| S9.4.A1 | Ensure that data stored on decentralized platforms like IPFS or Arweave is encrypted and access-controlled. |  | ✓ | ✓ |  |
| S9.4.A2 | Implement mechanisms for data redundancy and backup to ensure data availability. |  | ✓ | ✓ |  |
